# Stock-Analysis-Project
Correlation Matrix on Defence and Oil Stocks, Sample Project , Python
Basically, this table shows you if your stocks are teaming up or doing their own thing.

It uses a score between -1.0 and 1.0 to measure the relationship:
• The 1.0 Score: This is a "perfect match." It means two stocks move exactly the same way. If one jumps 2%, the other usually does too.
• High Scores (Red): These stocks are like best friends. They react to the same news (like a war or oil prices) at the same time.
• Low Scores (Blue/Grey): These stocks don't really affect each other. If one crashes, the other might stay perfectly fine.
The goal is to make sure your whole list isn't just one giant "red" block. If everything moves together, you’re taking a bigger risk. This table helps you see if you actually have a variety of stocks or if you just bought 25 versions of the same thing.
